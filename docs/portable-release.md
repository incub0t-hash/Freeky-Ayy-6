The portable runtime includes the best-run VIctory executable, shader-cache preparation from your own game files, checkpoint, launch settings, memory monitoring, Microsoft runtime installer, checksums and the full local source history with development branches.

Download and extract the ZIP, then drag your own game_scarlett_master.exe onto Play.cmd. Its game folder must contain shaders.rpf and the matching game data.

The first launch generates shaders and driver pipelines locally. The reference diner capture measured about 1.08 FPS with visible faces and clothing. Missing surfaces, lighting defects and variable streaming remain under development.
